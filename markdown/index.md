## 双份文档约定

每份资料保留两个对应文件：

```text
markdown/<相同目录>/<文档名>.md
docs/<相同目录>/<文档名>.html
```

- `markdown/`：方便克隆仓库后搜索、编辑和审查差异。
- `docs/`：方便通过 GitHub Pages 或本地浏览器阅读。
- 内容修改以 Markdown 为源，同时同步对应 HTML。
